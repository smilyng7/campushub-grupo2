# API Express (alternativa no activa)

El flujo principal de CampusHub usa [`api-mock`](../api-mock/README.md), que proporciona el API compartido en el puerto 3000 y persiste en `api-mock/db.json`.

Esta carpeta está reservada para una posible implementación alternativa con Express. Actualmente no contiene una aplicación ejecutable ni debe iniciarse para probar los portales.
